Arrays are usually the first data structure we study, but the important part is not memorizing individual solutions. The goal is to recognize a small set of patterns that appear again and again.

## What to learn first

1. Traverse an array without losing track of the current best answer.
2. Update an array in place using one or two pointers.
3. Use a `HashMap` or `HashSet` when repeated lookup is the expensive step.
4. Use prefix information when many questions ask about a range.
5. Sort only when the ordering helps more than it costs.

## A useful habit

Before writing code, say what each variable means. If you use two pointers, define the role of both pointers. If you keep a running answer, explain what is guaranteed to be true after every iteration.

That sentence is often the real solution. The Java code is only its implementation.
